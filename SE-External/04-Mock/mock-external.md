# Mock SE Lab External (four questions)
Modeled on CR's 21–22 Nov announcements; exact exam questions unknown.

**Q1 — SRS**: Problem: Online Hospital Appointment System. Write (a) abstract, (b) 5 functional requirements, (c) 5 non-functional requirements, (d) 3 user categories and each workflow, (e) one complete use-case textual description. Check that FR statements are observable, NFR targets testable, and actors consistent.

**Q2 — UML in StarUML**: Create **one** randomly selected diagram for the same appointment system: Class OR Sequence (book appointment) OR Use Case OR Component. Export/save and self-check connectors, labels and layout. Practise all four before exam.

**Q3 — Docker/Compose**: Containerize an Nginx web page, then explain how to use a two-service Compose file with an app and a database. Show working `docker build`, `docker run`, `docker ps`, logs; or `docker compose config/up/ps/down`.

**Q4 — Jenkins/Kubernetes alternate**: Option A: configure Jenkins job to clone a Maven repository, build it and trigger from GitHub. Option B: create Nginx Minikube Deployment, scale to 4 replicas, expose and verify endpoint, inspect logs/describe. In a second round replace with Git conflict/patch or AWS EC2/Nagios scenario.

**Viva rapid fire:** FR vs NFR? include vs extend? Class vs component? Image vs container? Dockerfile vs Compose? Maven clean/test/package/install? Freestyle vs pipeline? Scripted vs Declarative? Webhook vs polling? Pod vs Deployment vs Service? Nagios host vs service? EC2 SG vs key pair?

Do not say a practical succeeded until the running tool actually demonstrates success.
